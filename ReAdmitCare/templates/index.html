🧹 Data Preprocessing

Missing Values

Missing values represented by "?" were converted and handled using median imputation for numerical variables and an "Unknown" category for categorical variables.

Feature Removal

Identifier and high-missing-value columns such as encounter_id, patient_nbr, weight, payer_code and medical_specialty were removed.

Target Encoding

Readmission values were converted into a binary classification target: 1 for readmission within 30 days and 0 otherwise.

🔍 Feature Importance Analysis

The XGBoost model identifies the processed features that contribute most to 30-day readmission prediction.

💡 Key Finding

The most influential feature in the trained XGBoost model is number_inpatient, representing previous inpatient visits. This indicates that previous hospital utilization is an important factor associated with readmission risk.

🚀 Project Outcome

  • Developed an end-to-end healthcare machine learning system.
  • Processed more than 100,000 hospital encounter records.
  • Built multiple classification models for 30-day readmission prediction.
  • Built multiple regression models for hospital stay prediction.
  • Compared model performance using Accuracy, Precision, Recall, F1 Score and ROC-AUC.
  • Evaluated regression models using MAE, RMSE and R².
  • Created visual analytics and feature importance analysis.
  • Integrated the trained models into a Flask web application.
